# 🕌 Islami App

Islami App is a cross-platform mobile application built with Flutter, providing users with essential daily Islamic features through a clean, responsive, and intuitive user interface.

## ✨ Features

- 📖 Browse all 114 Quran Surahs.
- 🔍 Search Quran Surahs by name.
- 📚 Read complete Surahs with a clean reading experience.
- 📜 Browse and read Hadith.
- 📿 Digital Sebha (Tasbeeh Counter).
- 📻 Listen to Islamic Radio.
- 🕌 View Prayer Times.
- 🕓 Recently Read Surahs.
- 📱 Responsive UI for different screen sizes.
- 🚀 Smooth navigation and modern user experience.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Ali-emad-25/Islami_App.git
```

Navigate to the project

```bash
cd islami_app
```

Install dependencies

```bash
flutter pub get
```

Run the app

```bash
flutter run
```
